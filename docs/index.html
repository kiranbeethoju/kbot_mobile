KBot Mobile

A private, offline-first AI companion for Android. Voice transcription, local LLM chat, semantic memory search, and scheduled intelligence — all running on-device.

Kotlin 2.1 Android 10+ 100% Offline Open Source

Download APK 976 MB

Requires Android 10+  ·  Models installed separately  ·  No internet needed for core features

What It Does

🎙️

Voice Notes

One-tap recording with offline transcription via whisper.cpp. Your voice notes stay on your device, always.

🧠

Local LLM Chat

Chat with Gemma 4 running on-device via llama.cpp. Tool use: set alarms, call contacts, send messages — all from natural language.

🔍

Semantic Search

Find memories by meaning, not just keywords. MiniLM embeddings + cosine similarity search across your entire memory graph.

🤖

Automation Engine

Scheduled summaries, forgotten memory resurfacing, keyword tagging, habit reflection. Configurable polling, battery-aware execution.

🔔

Tool Execution

LLM outputs JSON tool calls — the app runs them. Notifications, alarms (AlarmManager), dialer, SMS composer, call log, contacts.

☁️

Cloud Fallback

Optional NVIDIA NIM API streaming with Nemotron Nano Omni. Toggle between local and cloud mode with one tap.

Pipeline

Record → Load Whisper → Transcribe → Unload Whisper → Load Embeddings → Generate Vector → Unload → Store in Room DB // one model at a time Query → Embed → Cosine Similarity → Top-K Results → Keyword Fallback → LLM Summary → Response // search pipeline RuleScheduler → Query pending rules → Execute → Notify // automation loop

Get Started

# Clone the repo
git clone https://github.com/kiranbeethoju/kbot_mobile.git
cd kbot_mobile

# Clone dependencies
git clone https://github.com/ggml-org/llama.cpp ../llama.cpp

# Build with JDK 17
export JAVA_HOME=/opt/homebrew/Cellar/openjdk@17/17.0.19/libexec/openjdk.jdk/Contents/Home
./gradlew assembleDebug

# Install
adb install -r app/build/outputs/apk/debug/app-debug.apk
./scripts/install-models-to-device.sh
